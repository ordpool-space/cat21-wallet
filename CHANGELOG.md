# Changelog

CAT-21 wallet is released as tags `cat21-v*` built by the
`extension:trusted-build` workflow (a signed, attested `.zip`). The canonical
per-release notes live on the GitHub Releases page:

https://github.com/ordpool-space/cat21-wallet/releases

Verify a downloaded build with:

```
gh attestation verify cat21-wallet-extension.zip --repo ordpool-space/cat21-wallet
```
